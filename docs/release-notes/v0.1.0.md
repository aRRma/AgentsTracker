Первый публичный релиз. Telegram-бот, через который вы ставите задачи Claude Code на своём
компьютере: пишете боту → на ПК запускается `claude` в папке проекта → ответ приходит в чат.
Каждое опасное действие агент подтверждает у вас кнопкой. Белый IP и открытые порты не нужны.

## Что внутри

- **Задачи текстом, подтверждения кнопками.** «Разрешить», «Всегда», «Отклонить»
  и «Отклонить с причиной»; правила «Всегда» помнятся для конкретного репозитория (`/rules`).
- **Разговор не теряется.** Сессия живёт между сообщениями и переживает перезапуск шлюза;
  сессии ведутся по папкам проектов (`/sessions`).
- **Настройки кнопками.** `/menu`: проект, модель, effort, режим разрешений, скиллы
  и плагины Claude Code, остаток тарифа и расход по дням.
- **Веб-монитор** на `http://127.0.0.1:5100` — текущая задача, история запусков, аудит и лог.
  Только показывает, ничего не меняет.
- **Установка одной командой.** `AgentsTracker.Gateway.exe install --start`: автозапуск при
  входе в Windows, настройки переезжают в `%LOCALAPPDATA%\AgentsTracker`, токен шифруется DPAPI.
- **Docker** — тот же шлюз на macOS и Linux, и единственный режим, где агент видит только
  смонтированные папки.

Барьеры доступа: список разрешённых пользователей и только личные чаты; порт разрешений —
всегда `127.0.0.1` плюс токен в заголовке; аудит пишет, кто что разрешил, без секретов.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне репозиториев,
например `C:\Apps\AgentsTracker`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.0-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.0-win-x64.zip` | меньше размером, нужен установленный [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) |

Дальше — три шага (подробнее в `УСТАНОВКА.txt` внутри архива):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken`, `ProjectPath` и свой числовой id в
   `Channel:Settings:AllowedUserIds` (id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя»).
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

## Что нужно знать

- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Денег шлюз не считает: в статистике ходы, токены и время, стоимость не показывается.
