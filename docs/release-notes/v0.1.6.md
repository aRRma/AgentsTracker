Выпуск про слова: одно и то же место в боте больше не называется по-разному. Кнопки, сообщения
и страница монитора приведены к единым названиям, поведение не менялось.

## Что нового

- **Рабочая папка везде «проект».** Кнопка меню теперь «📁 Проект», и в списках, подсказках и
  сообщениях о переключении больше не встречается «репозиторий».
- **«📊 Расход» вместо «Статистики».** Экран с ходами, токенами и лимитами тарифа называется
  одинаково в меню, в `/usage` и на странице монитора.
- **Карточка с кнопками — «подтверждение».** Когда агенту нужно ваше «да», и в чате, и в
  подсказках это называется подтверждением, а не то разрешением, то запросом.
- **Понятные отказы при отправке файлов боту.** Если вложение не приняли — слишком большое,
  приём выключен, не удалось скачать — в ответе так и написано «вложение», без путаницы с
  картинкой или файлом.
- **Разделы монитора переименованы**: «Статус», «Расход по дням», «Журнал». Ссылки сверху
  страницы совпадают с заголовками разделов.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне репозиториев,
например `C:\Apps`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.6-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.6-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Внутри архива — папка `AgentsTracker-v0.1.6-…` с приложением и `install.txt` рядом с ней.
Дальше три шага (подробнее в `install.txt`):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken`, `ProjectPath` и свой числовой id в
   `Channel:Settings:AllowedUserIds` (id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя»).
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

Обновление с v0.1.5: `uninstall` в старой папке → распаковать новый архив → перенести свой
`appsettings.Local.json`, если он лежал рядом с exe → `install --start`. Настройки, сессии и
журнал в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Секреты, лежащие внутри проекта (`.env`, локальный `appsettings.Local.json`), под запрет
  на отправку файлов не попадают: держите их вне репозитория или в папке данных.
- Денег шлюз не считает: в расходе ходы, токены и время, стоимость не показывается.
