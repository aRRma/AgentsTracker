Агент теперь сам присылает файлы в чат: отчёт, разбор или скриншот приходят вложением, а не
простынёй текста. Плюс отправка перестала терять части ответа при ограничении Telegram
и переписан быстрый старт — он про готовый архив, а не про сборку из исходников.

## Что нового

- **Файл от агента в чат.** Агент отправляет файл сам, без карточки «разрешить?»: политику
  держит шлюз. Разрешены только файлы из папки текущего проекта — папка данных шлюза, пути
  через symlink и junction отклоняются, — и только `.md .txt .json .cs .js .html` документом
  и `.png .jpg .jpeg` фото. Каждая отправка и каждый отказ пишутся в аудит (`file.send`).
- **Ответ не теряется при ограничении Telegram.** Если Telegram просит подождать посреди
  длинного ответа, шлюз ждёт указанное время и повторяет ту же часть — раньше она могла
  пропасть молча. Так же теперь ведёт себя и отправка файла.
- **Документация.** README начинается с установки из релиза, сборка из исходников — отдельным
  разделом. Появилась вики на GitHub — зеркало README и `docs/`, собирается автоматически.

## Важное уточнение про архивы

Лёгкому архиву `…-win-x64.zip` нужен **ASP.NET Core Runtime 10**, а не просто .NET Runtime:
шлюз собран Web SDK и просит два фреймворка. В прошлом релизе это было написано неточно.
Сомневаетесь — берите `…-self-contained.zip`, там среда выполнения внутри.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне репозиториев,
например `C:\Apps\AgentsTracker`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.1-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.1-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Дальше — три шага (подробнее в `УСТАНОВКА.txt` внутри архива):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken`, `ProjectPath` и свой числовой id в
   `Channel:Settings:AllowedUserIds` (id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя»).
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

Обновление с v0.1.0: `uninstall` → распаковать новый архив поверх → `install --start`.
Настройки, сессии и аудит в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Секреты, лежащие внутри проекта (`.env`, локальный `appsettings.Local.json`), под запрет
  на отправку файлов не попадают: держите их вне репозитория или в папке данных.
- Денег шлюз не считает: в статистике ходы, токены и время, стоимость не показывается.
