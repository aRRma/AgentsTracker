Выпуск про темы: в одном чате с ботом теперь можно вести несколько задач параллельно.

## Что нового

- **Темы.** Включите темы для бота в @BotFather и создайте тему в чате — шлюз спросит «Тип
  темы»: проект или беседа. У каждой темы своя сессия, модель и effort, темы работают
  параллельно. `/stop` в теме прерывает только её.
- **Беседа** — тема без проекта: поиск в сети и сайты, без карточек, файлов и картинок.
- **Один проект — один запуск.** Если две темы работают в одном проекте, вторая ждёт и пишет
  «⏳ В проекте идёт другой запуск».
- **`/stop` в кнопке «Меню».**
- **Лог в файле.** Лог теперь пишется в `%LOCALAPPDATA%\AgentsTracker\logs\`, по файлу на день,
  хранится 14 дней. Токены и пароли в нём, как и в мониторе, замаскированы.
- **Подробнее в журнале.** `/audit` показывает расход каждого запуска (ходы, токены, кэш,
  модель), причину остановки (`/stop` или предел времени) и ответы, которые не дошли до чата.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне проектов,
например `C:\Apps`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.13-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.13-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Внутри архива — папка `AgentsTracker-v0.1.13-…` с приложением, `install.txt` и
`claude-settings.example.json` рядом с ней. Дальше три шага (подробнее в `install.txt`):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken` и `ProjectPath`. В `Channel:Settings:AllowedUserIds` пока
   оставьте `[ 0 ]`: свой числовой id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя».
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

Обновление с v0.1.12: `uninstall` в старой папке → распаковать новый архив → перенести свой
`appsettings.Local.json`, если он лежал рядом с exe → `install --start`. Настройки, сессии и
журнал в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- С темами в ленту не пишите: набранное там Telegram переносит в новую тему. В ленте остаются
  только служебные сообщения и команды из кнопки «Меню».
- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Денег шлюз не считает: в расходе ходы, токены и время, стоимость не показывается.
