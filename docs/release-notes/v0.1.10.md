Выпуск про ветки git: теперь видно, в какой ветке работает агент, а правила для агента легко
перенести на другой компьютер.

## Что нового

- **Ветка проекта на виду.** Пока идёт задача, в строке «Работаю…» стоит `🌿 master` или другая
  ветка. Под ответом — тоже. Если агент сам переключил ветку, под ответом видно, откуда и куда:
  `master → fix`.
- **Ветка на экранах «Статус» и «Проект».** Задача больше не уйдёт незаметно не в ту ветку.
- **Worktree в списке проектов.** Соседние папки одного репозитория помечены 🌳 и подписаны своей
  веткой — их легко отличить друг от друга.
- **Ветка в журнале и мониторе** — у каждого запуска.
- **Правила для агента в архиве.** Рядом с приложением лежит `claude-settings.example.json` —
  готовый набор правил: что агент делает без вопроса, о чём спрашивает и что ему запрещено.
  Как его поставить — шаг 5 в `install.txt`.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне проектов,
например `C:\Apps`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.10-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.10-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Внутри архива — папка `AgentsTracker-v0.1.10-…` с приложением, `install.txt` и
`claude-settings.example.json` рядом с ней. Дальше три шага (подробнее в `install.txt`):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken`, `ProjectPath` и свой числовой id в
   `Channel:Settings:AllowedUserIds` (id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя»).
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

Обновление с v0.1.9: `uninstall` в старой папке → распаковать новый архив → перенести свой
`appsettings.Local.json`, если он лежал рядом с exe → `install --start`. Настройки, сессии и
журнал в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- Если у вас уже есть `%USERPROFILE%\.claude\settings.json`, не затирайте его примером из архива:
  перенесите только списки `allow`, `ask` и `deny`.
- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Денег шлюз не считает: в расходе ходы, токены и время, стоимость не показывается.
