Выпуск про контекст и быстрые вопросы: видно, сколько места занял разговор, его можно сжать,
а мимолётный вопрос больше не засоряет рабочую сессию.

## Что нового

- **Вопрос вне сессии.** `/ask <вопрос>` или кнопка «💬 Вопрос» в меню — ответ отдельной
  моделью (по умолчанию sonnet), без проекта и без истории. Текущий разговор с агентом не
  затрагивается. Модель для вопросов задаётся в настройках: `Question:Model`, `Question:Effort`.
- **Экран «📦 Контекст» в `/menu`.** Показывает, насколько заполнен контекст сессии и из чего
  он состоит. Отсюда же — «Сжать» и «Новая сессия»; обе кнопки сначала переспрашивают.
- **Подпись под ответом.** Под каждым ответом видно, какая модель на самом деле ответила и с
  каким effort — например `opus-5(H)`, — а ещё число ходов и время. У вопроса вместо сессии
  стоит «💬 вопрос».

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне репозиториев,
например `C:\Apps`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.7-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.7-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Внутри архива — папка `AgentsTracker-v0.1.7-…` с приложением и `install.txt` рядом с ней.
Дальше три шага (подробнее в `install.txt`):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken`, `ProjectPath` и свой числовой id в
   `Channel:Settings:AllowedUserIds` (id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя»).
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

Обновление с v0.1.6: `uninstall` в старой папке → распаковать новый архив → перенести свой
`appsettings.Local.json`, если он лежал рядом с exe → `install --start`. Настройки, сессии и
журнал в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Секреты, лежащие внутри проекта (`.env`, локальный `appsettings.Local.json`), под запрет
  на отправку файлов не попадают: держите их вне репозитория или в папке данных.
- Денег шлюз не считает: в расходе ходы, токены и время, стоимость не показывается.
