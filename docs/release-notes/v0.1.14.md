Выпуск про тему «Работа»: удалённая работа со всем компьютером из Telegram.

## Что нового

- **Тема «Работа».** Третий тип темы рядом с «Проект» и «Беседа». Агенту доступен весь компьютер:
  команды, файлы, ваши MCP-серверы (например, браузер), поиск в сети и картинки из чата. У темы
  своя постоянная папка, файл или скриншот агент присылает из неё.
- **Всё критичное — карточкой.** Режим в «Работе» всегда `default`, `/mode` не меняет его. Кнопки
  «Всегда» на карточках нет: одно нажатие не разрешит команду на всей машине навсегда. Поиск в сети
  идёт без карточки, а открыть страницу агент сначала спрашивает.
- **Только для тех, кому разрешено.** По умолчанию «Работа» выключена и кнопки нет ни у кого.
  Включается только на самом компьютере: впишите свой id в `Gateway:Work:AllowedUserIds` в
  `appsettings.Local.json`. Уберёте id — задачи в такой теме получат отказ.
- **Агент не правит настройки шлюза.** В любой теме шлюз без карточки отказывает агенту в правке
  своей папки данных, а в «Работе» — ещё и в правке настроек самого агента: правило оттуда сняло бы
  карточки на всей машине.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне проектов,
например `C:\Apps`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.14-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.14-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Внутри архива — папка `AgentsTracker-v0.1.14-…` с приложением, `install.txt` и
`claude-settings.example.json` рядом с ней. Установка по шагам — в `install.txt`.

Обновление с v0.1.13: `uninstall` в старой папке → распаковать новый архив → перенести свой
`appsettings.Local.json`, если он лежал рядом с exe → `install --start`. Настройки, сессии и
журнал в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- Перед включением «Работы» прочитайте свои правила `allow` в `~/.claude/settings.json`: всё, что
  там разрешено, в «Работе» идёт без карточки уже на всей машине. Запретите чтение папки данных
  шлюза и включите облачный пароль в Telegram — кто получит ваш аккаунт, получит и компьютер.
  Подробно — раздел про «Работу» в `safety.md`.
- Прав администратора у «Работы» нет: шлюз работает от вашей учётной записи без повышения.
- Windows 10/11. Для macOS и Linux своей установки нет — там только Docker, и «весь компьютер» в нём —
  это контейнер.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
