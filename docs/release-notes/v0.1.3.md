Теперь боту можно прислать картинку: скриншот ошибки, фото доски, макет. Подпись к картинке
становится задачей, и агент видит сам файл.

## Что нового

- **Картинки из чата.** Отправьте боту PNG или JPEG с подписью — агент откроет картинку и
  выполнит то, что написано в подписи. Можно прислать несколько разом, альбомом.
- **Мелкий текст на скриншоте.** Telegram сжимает фото, и подписи в интерфейсе становятся
  нечитаемыми. Отправляйте такой скриншот «как файл» — придёт без сжатия.
- **Картинки не копятся.** Файлы лежат сутки, чистятся при запуске шлюза и по `/new`. Предел
  размера — 10 МБ, всё это меняется в настройках (`Attachments`).
- **Агент видит только свои картинки.** Ему открывается папка с картинками этого чата, а не
  папка данных шлюза, где лежат токен и настройки.

## Установка

Скачайте архив под свой случай и распакуйте в постоянную папку вне репозиториев,
например `C:\Apps`:

| Архив | Когда брать |
|---|---|
| `AgentsTracker-v0.1.3-win-x64-self-contained.zip` | среда выполнения внутри, .NET на машине не нужен |
| `AgentsTracker-v0.1.3-win-x64.zip` | меньше размером, нужен [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) |

Внутри архива — папка `AgentsTracker-v0.1.3-…` с приложением и `install.txt` рядом с ней.
Дальше три шага (подробнее в `install.txt`):

1. Установите Claude Code и войдите в аккаунт: `irm https://claude.ai/install.ps1 | iex`,
   в новом окне запустите `claude`. Заведите бота у [@BotFather](https://t.me/BotFather).
2. Скопируйте `appsettings.Local.example.json` рядом как `appsettings.Local.json` и впишите
   `Channel:Settings:BotToken`, `ProjectPath` и свой числовой id в
   `Channel:Settings:AllowedUserIds` (id покажет консольный запуск `.\AgentsTracker.Gateway.exe`
   строкой «Отклонено сообщение от постороннего пользователя»).
3. `.\AgentsTracker.Gateway.exe install --start` — в Telegram придёт «🔌 Шлюз запущен».

Обновление с v0.1.2: `uninstall` в старой папке → распаковать новый архив → перенести свой
`appsettings.Local.json`, если он лежал рядом с exe → `install --start`. Настройки, сессии и
аудит в `%LOCALAPPDATA%\AgentsTracker` не затрагиваются.

## Что нужно знать

- Windows 10/11. Для macOS и Linux своей установки пока нет — там только Docker.
- Компьютер должен быть включён и в него нужно быть вошедшим: Claude Code читает вход
  в аккаунт из вашего профиля, поэтому службой шлюз не ставится.
- Агент видит всю машину — ограничить его до одной папки можно только в Docker.
- Секреты, лежащие внутри проекта (`.env`, локальный `appsettings.Local.json`), под запрет
  на отправку файлов не попадают: держите их вне репозитория или в папке данных.
- Денег шлюз не считает: в статистике ходы, токены и время, стоимость не показывается.
