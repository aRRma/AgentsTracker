# AgentsTracker

Телеграм-бот, через который вы даёте задачи Claude Code на своём компьютере.

Пишете боту → на ПК запускается `claude` в папке проекта → бот присылает ответ.
Когда агент хочет что-то изменить или выполнить, в чат приходит карточка с кнопками
«Разрешить / Отклонить / Всегда».

Компьютер должен быть включён. Белый IP и проброс портов не нужны.

## Что умеет

- Задача агенту — любым сообщением.
- Подтверждение каждого опасного действия кнопкой.
- Разговор не теряется: контекст живёт между сообщениями и переживает перезапуск.
- Смена проекта, модели и глубины размышлений прямо из чата.
- Остаток тарифа в чате. Платные кредиты агент потратить не может.
- Журнал: кто, что и когда попросил.
- Веб-монитор на этом же ПК: <http://127.0.0.1:5100/> — что агент делает сейчас, очередь,
  ожидающие подтверждения, история, статистика (CSV для Excel), аудит и лог.

## Запуск за 5 шагов

**1. Поставьте Claude Code** (в PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Откройте новое окно, проверьте `claude --version`. Один раз запустите `claude` и войдите
в аккаунт.

**2. Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`.
В ответ придёт токен вида `123456789:AA...` — скопируйте.

**3. Заполните настройки.** Скопируйте
`src/AgentsTracker.Gateway/appsettings.Local.example.json` рядом под именем
`appsettings.Local.json` и впишите:

```json
"BotToken": "токен от BotFather",
"ProjectPath": "C:/путь/к/вашему/проекту"
```

**4. Запустите и узнайте свой id:**

```powershell
dotnet run --project src\AgentsTracker.Gateway
```

Напишите боту что угодно. В окне появится строка:

```
warn: Отклонено сообщение от постороннего пользователя. user id: 123456789
```

Впишите номер в настройки:

```json
"AllowedUserIds": [ 123456789 ]
```

**5. Запустите снова** той же командой. Готово — пишите боту задачу.

## Автозапуск при входе в Windows

```powershell
pwsh -File scripts\install-autostart.ps1
```

Скрипт соберёт приложение, зашифрует токен, перенесёт настройки в защищённую папку
`%LOCALAPPDATA%\AgentsTracker\` и создаст задачу Планировщика. Снять — тот же скрипт
с `-Uninstall`.

## Перезапуск

Настройки читаются один раз при старте: поправили `appsettings.Local.json` — перезапустите.

Запускали вручную:

```powershell
Get-Process AgentsTracker.Gateway | Stop-Process -Force
dotnet build src\AgentsTracker.Gateway
Start-Process src\AgentsTracker.Gateway\bin\Debug\net10.0\AgentsTracker.Gateway.exe
```

Настроен автозапуск:

```powershell
Stop-ScheduledTask -TaskName 'AgentsTracker Gateway'
Start-ScheduledTask -TaskName 'AgentsTracker Gateway'
```

Бот напишет «🔌 Шлюз запущен». Если перезапуск пришёлся на работающую задачу, бот
предупредит, что она прервана: сделанное сохранено, напишите «продолжай».

## Команды в чате

| Команда | Что делает |
|---|---|
| любой текст | задача агенту |
| `/menu` | все настройки кнопками |
| `/status` | что происходит сейчас и остаток тарифа |
| `/sessions` | сессии проекта: переключить, начать новую, остановить запуск |
| `/new` | начать разговор заново |
| `/stop` | прервать текущую задачу |
| `/agent` | модель, effort, режим разрешений |
| `/model`, `/effort`, `/mode` | то же текстом: `/model sonnet`, `/effort high`, `/mode plan` |
| `/skills` | скиллы Claude Code, запуск кнопкой; «Плагины» — включить или выключить плагин, «Обновить» — перечитать список |
| `/project` | сменить папку проекта |
| `/usage` | остаток тарифа и расход |
| `/rules` | выданные «Всегда» для этого репозитория; `/rules clear` — снять все |
| `/audit` | последние действия |
| `/help` | справка |

Всё это есть и по кнопке «Меню» в поле ввода Telegram.

## Основные настройки

Файл `appsettings.Local.json`, секция `Gateway`:

| Ключ | Зачем |
|---|---|
| `BotToken` | токен от @BotFather |
| `AllowedUserIds` | кому можно управлять ботом |
| `ProjectPath` | папка проекта по умолчанию |
| `Projects` / `ProjectsRoot` | какие папки показывать в меню выбора проекта |
| `Agent` | какой агент за шлюзом; пока только `claude` |
| `Claude:Executable` | путь к `claude.exe`, если автопоиск не находит |
| `Claude:BuiltInSkills` | встроенные скиллы для `/skills`, строки `"/команда \| описание \| подсказка аргументов"` |
| `Model`, `Effort` | модель и глубина размышлений по умолчанию |
| `PermissionMode` | что можно без спроса: `default`, `acceptEdits`, `auto`, `plan` |
| `Proxy` | прокси, если Telegram недоступен напрямую |
| `MonitorPort` | порт веб-монитора (5100), `0` — выключить |
| `McpPort` | порт, по которому `claude` спрашивает разрешения у бота (5099) |
| `ApprovalTimeoutMinutes`, `RunTimeoutMinutes` | сколько ждать ответа на карточку (15) и всю задачу (60) |

Полный список — в `appsettings.json`. Устройство проекта — [CLAUDE.md](CLAUDE.md), подробности — папка [docs/](docs/).

## Безопасность

Бот даёт доступ к командной строке вашего ПК. Поэтому:

- **обязательно** заполните `AllowedUserIds` — единственная защита от посторонних;
- групповые чаты бот игнорирует, только личные;
- токен бота хранится зашифрованным (DPAPI): расшифрует только ваша учётная запись на этой
  машине;
- сетевой порт открыт только внутри ПК (`127.0.0.1`) и закрыт секретным токеном;
- веб-монитор тоже только на `127.0.0.1`, но без пароля: его видит любой, кто вошёл на этот
  ПК. Он только показывает и ничего не меняет; не нужен — `"MonitorPort": 0`;
- отключить подтверждения из чата нельзя — только правкой файла на самой машине;
- запретить что-то намертво — в `.claude/settings.local.json` проекта:

  ```json
  { "permissions": { "deny": ["Bash(rm *)"] } }
  ```

  Кнопка «Всегда» такие запреты не обходит;
- правила «Всегда» привязаны к репозиторию: разрешённое в одном не действует в другом;
- «Плагины» в `/skills` правят ваш `~/.claude/settings.json` — то же, что `/plugin` в самом
  Claude Code; плагин, заданный в настройках проекта, из чата не переключается;
- если команда или правка не влезла в карточку, перед ней приходит файл с полным текстом —
  не разрешайте, не заглянув.

## Если что-то не так

| Симптом | Причина |
|---|---|
| Бот молчит | не заполнен `AllowedUserIds` или неверный токен |
| Правка настроек не подействовала | нужен перезапуск — см. выше |
| В меню не все репозитории | не задан `ProjectsRoot`; список листается `◀ ▶` |
| `claude` не найден | не поставлен CLI (шаг 1) или не открыто новое окно PowerShell |
| Сборка падает с `MSB3021` | шлюз запущен — остановите: `Get-Process AgentsTracker.Gateway \| Stop-Process` |
| Кнопки не приходят | `PermissionMode` стоит `auto` — поставьте `default` |
| В логе крякозябры | консоль в cp866; смотрите лог в PowerShell |
