# AgentsTracker

Телеграм-бот, через который вы разговариваете с Claude Code на своём компьютере.

Пишете боту задачу → на ПК запускается `claude` в папке вашего проекта → бот присылает ответ.
Если агент хочет что-то изменить или выполнить команду, он спрашивает разрешение кнопкой в чате.

Компьютер должен быть включён. Белый IP и проброс портов не нужны.

## Что умеет

- Задача агенту — любым сообщением в чат.
- Кнопки «Разрешить / Отклонить / Всегда» на каждое опасное действие.
- Диалог не теряется: контекст живёт между сообщениями и переживает перезапуск.
- Переключение между вашими репозиториями прямо из чата.
- Выбор модели и «сколько думать».
- Показ остатка тарифа. Платные кредиты агент потратить не может.
- Журнал: кто, что и когда попросил.

## Запуск за 5 шагов

**1. Поставьте Claude Code** (в PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Закройте окно, откройте новое и проверьте: `claude --version`.
Один раз запустите `claude` и войдите в свой аккаунт.

**2. Создайте бота.** Напишите в Telegram [@BotFather](https://t.me/BotFather), отправьте
`/newbot`, придумайте имя. В ответ придёт длинный токен вида `123456789:AA...` — скопируйте его.

**3. Заполните настройки.** Скопируйте файл
`src/AgentsTracker.Gateway/appsettings.Local.example.json`
рядом, под именем `appsettings.Local.json`, и впишите два значения:

```json
"BotToken": "сюда токен от BotFather",
"ProjectPath": "C:/путь/к/вашему/проекту"
```

**4. Запустите и узнайте свой id:**

```powershell
dotnet run --project src\AgentsTracker.Gateway
```

Напишите боту любое сообщение. В окне появится строка с вашим номером:

```
warn: Отклонено сообщение от постороннего пользователя. user id: 123456789
```

Впишите этот номер в настройки:

```json
"AllowedUserIds": [ 123456789 ]
```

**5. Запустите снова** той же командой. Готово — пишите боту задачу.

## Чтобы включался сам при старте Windows

```powershell
pwsh -File scripts\install-autostart.ps1
```

Скрипт соберёт приложение, зашифрует токен, спрячет настройки в защищённую папку
`%LOCALAPPDATA%\AgentsTracker\` и создаст задачу «запускать при входе в систему».
После этого запускать вручную не нужно.

## Перезапуск после правки настроек

Настройки читаются один раз при запуске. Поправили `appsettings.Local.json` — перезапустите
шлюз, иначе он продолжит работать со старыми значениями.

Если запускали вручную:

```powershell
Get-Process AgentsTracker.Gateway | Stop-Process -Force
dotnet build src\AgentsTracker.Gateway
Start-Process src\AgentsTracker.Gateway\bin\Debug\net10.0\AgentsTracker.Gateway.exe
```

Остановить нужно до сборки: запущенный шлюз держит свой `.exe`, и сборка падает с `MSB3021`.

Если настроен автозапуск:

```powershell
Stop-ScheduledTask -TaskName 'AgentsTracker Gateway'
Start-ScheduledTask -TaskName 'AgentsTracker Gateway'
```

Что шлюз поднялся, видно по последней строке журнала — `/audit` в чате покажет `gateway старт`.

## Команды в чате

| Команда | Что делает |
|---|---|
| любой текст | задача агенту |
| `/menu` | меню настроек кнопками |
| `/new` | начать разговор заново |
| `/stop` | прервать текущую задачу |
| `/status` | что сейчас происходит |
| `/project` | сменить папку проекта |
| `/sessions` | переключиться на другой разговор |
| `/model` | сменить модель (opus / sonnet / haiku) |
| `/effort` | сколько модели думать (low … max) |
| `/mode` | что агенту можно делать без спроса |
| `/rules` | список выданных «Всегда»; `/rules clear` — снять все |
| `/usage` | остаток тарифа и расход |
| `/audit` | последние действия |
| `/help` | справка |

Всё это видно по кнопке «Меню» в поле ввода Telegram.

## Основные настройки

Файл `appsettings.Local.json`, секция `Gateway`:

| Ключ | Зачем |
|---|---|
| `BotToken` | токен от @BotFather |
| `AllowedUserIds` | кому можно управлять ботом |
| `ProjectPath` | папка проекта по умолчанию |
| `Projects` / `ProjectsRoot` | какие папки показывать в меню выбора проекта |
| `Model`, `Effort` | модель и глубина размышлений по умолчанию |
| `PermissionMode` | что можно без спроса: `default`, `acceptEdits`, `auto`, `plan` |
| `DailyBudgetUsd`, `RunBudgetUsd` | денежные предохранители, по умолчанию выключены |
| `Proxy` | прокси, если Telegram недоступен напрямую |

Полный список — в `appsettings.json`, устройство проекта — в [CLAUDE.md](CLAUDE.md).

## Безопасность

Бот даёт доступ к командной строке вашего ПК. Поэтому:

- **обязательно** заполните `AllowedUserIds` — это единственная защита от посторонних;
- бот принимает только личные сообщения, групповые чаты игнорирует;
- токен бота хранится зашифрованным (DPAPI), расшифровать его может только ваша учётная
  запись на этой машине;
- сетевой порт открыт только внутри компьютера (`127.0.0.1`) и закрыт секретным токеном;
- полностью отключить кнопки-подтверждения из чата нельзя — только правкой файла на самой машине;
- чтобы запретить что-то намертво, добавьте в `.claude/settings.local.json` вашего проекта:

  ```json
  { "permissions": { "deny": ["Bash(rm *)"] } }
  ```

  Такие запреты кнопка «Всегда» не обходит.

## Если что-то не так

| Симптом | Причина |
|---|---|
| Бот молчит | не заполнен `AllowedUserIds` или неверный токен |
| Правка настроек ничего не изменила | нужен перезапуск — см. раздел выше |
| В меню видно не все репозитории | не задан `ProjectsRoot`; список листается кнопками `◀ ▶` |
| `claude` не найден | не поставлен CLI (шаг 1) или не открыто новое окно PowerShell |
| Сборка падает с `MSB3021` | шлюз уже запущен — остановите: `Get-Process AgentsTracker.Gateway \| Stop-Process` |
| В логе крякозябры | консоль в cp866; смотрите лог в PowerShell |
| Кнопки не приходят | `PermissionMode` стоит `auto` — поставьте `default` |
