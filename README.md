  Шлюз между Telegram и Claude Code на вашем компьютере.<br>
  Пишете боту задачу — на ПК запускается <code>claude</code> в папке проекта — ответ приходит в чат.

- **Опасное — только с вашего согласия.** Команду или правку, которую вы не разрешили заранее,
  агент сначала подтверждает у вас: в чат приходит карточка с кнопками.
- **Сессия не теряется** между сообщениями и перезапусками: можно уточнять, не повторяя условие.
- **Файлы — в тот же чат.** Отчёт, таблицу или скриншот агент присылает файлом, а вы ему — картинку.

Нужен компьютер с Windows, который включён, и вы в него вошли. Белый IP и открытые порты не нужны.
Агент видит всё, что видит ваша учётная запись, а не только папку проекта, — прочитайте
[«Безопасность»](#безопасность) до первой задачи.

## Для чего

Для работы с кодом из любого места — и для всего, что лежит на домашнем компьютере.

| Что | Пример задачи |
|---|---|
| **Код** — поправить, проверить, объяснить | «Поправь падение при пустом списке и запусти тесты» |
| **Забытый файл** — найти и прислать | «Найди скан загранпаспорта в Документах и пришли сюда» |
| **Домашняя бухгалтерия** — свести выписки и чеки | «Сведи траты за квартал по категориям и пришли файлом» |
| **Заметки** — записать, найти, подвести итог | «Что я записывал про ремонт балкона?» |
| **Как дела дома** — диск, загрузки, домашний сервер | «Скачалось? Сколько осталось места на диске?» |

Подробнее, с примерами и настройкой, — [docs/use-cases.md](docs/use-cases.md).

## Как это работает

<p align="center">
  <img src="docs/images/architecture.png" width="900" alt="Схема: чат, шлюз, Claude Code, папка проекта, состояние и веб-монитор">
</p>

Шлюз работает на вашем ПК. Он получает задачу из Telegram, запускает Claude Code в папке проекта и
отдаёт ответ в чат. Когда агенту нужно подтверждение, он спрашивает шлюз, а шлюз — вас, карточкой с
кнопками. Входящие подключения не нужны: шлюз сам ходит в Telegram, а Claude Code — в Anthropic и
туда, куда вы ему разрешите.

## Установка

### Что нужно

- **Windows 10 или 11.** На macOS и Linux — пока только [Docker](docs/deployment.md#docker).
- **Claude Code** с входом по подписке. Каждая задача тратит лимит этой подписки. Проверка —
  `claude --version` в PowerShell. Если команды нет, выполните
  `irm https://claude.ai/install.ps1 | iex`, затем в новом окне запустите `claude` и войдите.
- **Бот в Telegram.** У [@BotFather](https://t.me/BotFather) — команда `/newbot`, скопируйте токен.
  Проверка, что Telegram доступен, — `curl.exe -sI https://api.telegram.org`. Если нет, понадобится
  прокси (`Proxy` в настройках).

### Шаги

1. **Скачайте архив** со страницы [Releases](https://github.com/aRRma/AgentsTracker/releases).
   Если сомневаетесь, берите `…-win-x64-self-contained.zip` (~50 МБ): в нём всё нужное. Архив
   `…-win-x64.zip` (~3 МБ) меньше, но требует
   [ASP.NET Core Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0).
2. **Распакуйте** его. Внутри — папка шлюза, `install.txt` с короткой инструкцией и
   `claude-settings.example.json`. Папку шлюза перенесите в постоянное место вне проектов, например
   в `C:\Apps\AgentsTracker`. Откройте в ней PowerShell: в Проводнике наберите `powershell` в адресной
   строке и нажмите Enter. Все команды ниже — в этом окне.
3. **Настройки.** Скопируйте `appsettings.Local.example.json` как `appsettings.Local.json` и откройте
   Блокнотом. В кавычках замените `BotToken` на токен бота, а `ProjectPath` — на папку, где будет
   работать агент. Путь пишите через `/`: `C:/Users/Вы/Documents`. `AllowedUserIds` пока оставьте
   `[ 0 ]`.
4. **Ваш id.** Запустите `.\AgentsTracker.Gateway.exe` и напишите боту что угодно. В окне появится
   `Отклонено сообщение от постороннего пользователя. Пользователь: telegram:123456789`. Впишите
   цифры вместо 0: `"AllowedUserIds": [ 123456789 ]`. Закройте шлюз по Ctrl+C. Если шлюз сразу
   завершился, причина написана в этом же окне.
5. **Автозапуск:** `.\AgentsTracker.Gateway.exe install --start`. Шлюз будет стартовать при входе в
   Windows, настройки переедут в `%LOCALAPPDATA%\AgentsTracker\`, токен зашифруется.
6. **Правила для агента** — что он делает без подтверждения, о чём спрашивает и что ему запрещено.
   Если файла `%USERPROFILE%\.claude\settings.json` нет, скопируйте туда пример:
   ```powershell
   Copy-Item <папка распаковки>\claude-settings.example.json $env:USERPROFILE\.claude\settings.json
   ```
   Если файл есть, не затирайте его — как перенести правила, написано в
   [docs/claude-permissions.md](docs/claude-permissions.md). Перезапуск не нужен.
7. **Проверьте.** В чат придёт «🔌 Шлюз запущен» с версией — напишите первую задачу. Не пришло —
   [«Если что-то не так»](docs/deployment.md#если-что-то-не-так).

**Обновление:** в старой папке `.\AgentsTracker.Gateway.exe uninstall`, затем новая папка шлюза на
место старой и в ней `.\AgentsTracker.Gateway.exe install --start`. Настройки, сессии и журнал
остаются в `%LOCALAPPDATA%\AgentsTracker\`, и править настройки теперь там.
**Удаление:** `.\AgentsTracker.Gateway.exe uninstall`.

Docker, сборка из исходников, все ключи настроек и перезапуск — [docs/deployment.md](docs/deployment.md).

## Как пользоваться

- **Задачу пишите обычным текстом.** Картинку можно прислать с подписью или без.
- **`/menu`** — всё кнопками: проект, модель, effort, режим, сессии, контекст, скиллы, расход.
- **`/stop`** прерывает запуск, **`/new`** начинает новую сессию, **`/status`** показывает, что идёт
  сейчас.
- **`/ask <вопрос>`** — быстрый вопрос вне сессии и проекта, с поиском в сети.
- **Темы.** Включите темы для бота в @BotFather — и в каждой теме будет свой проект и своя сессия.
  Темы работают параллельно. Тема без проекта — беседа: только поиск в сети.
- **`/help`** — все команды. Команды самого Claude Code (`/init`) уходят агенту как есть.

Веб-монитор на том же ПК — <http://127.0.0.1:5100>: статус, расход, история запусков, журнал и лог.
Он только показывает, управление — в чате. Все команды и подпись под ответом —
[docs/use-cases.md](docs/use-cases.md#команды).

## Безопасность

Агент видит всё, что видит ваша учётная запись Windows, а не только папку проекта. Поэтому:

- **обязательно** впишите свой id в `AllowedUserIds` — это единственная защита от посторонних.
  Шлюз отвечает только в личных чатах;
- держите режим `default`: в нём опасное приходит карточкой. Полностью выключить подтверждения из
  чата нельзя;
- если в проекте есть свои настройки агента (`.claude/`, `.mcp.json`), перед первой задачей шлюз
  спросит «Доверять проекту?». Чужому проекту не доверяйте, пока не прочитали его
  `.claude/settings.json`;
- секреты держите вне проекта: агент может прислать в чат любой файл проекта разрешённого типа;
- нужна изоляция — запускайте в [Docker](docs/deployment.md#docker): там агент видит только
  смонтированные папки.

Все риски и как их закрыть — [docs/safety.md](docs/safety.md).
