## Правила задачи

1. Работайте только в worktree. Давайте `dotnet build`, `git -C` и скриптам абсолютный путь
   worktree: cwd инструмента PowerShell — главная папка.
2. Не сливайте ветку `topics` в `master` до успешного смоук-теста.
3. Не трогайте боевой шлюз: MCP на `5099`, монитор на `5100`. Проверяйте на пробном
   экземпляре — `plan.md`, раздел «Проверка рядом с боевым шлюзом».
4. Не кладите токен тестового бота в репозиторий.
5. Ведите ревью ветки командой `code-review medium --fix topics`. Без имени ветки ревью
   возьмёт `master`.
6. Удалите папку `tasks/topics/` перед слиянием в `master`.

## Как начать следующую сессию

1. Откройте worktree `AgentsTracker-topics`. Из Telegram переключите `/project` на него.
2. Прочитайте `README.md`, потом `plan-rework.md`; `plan.md` и `summary.md` — по необходимости.
3. Начните с первого открытого пункта в списке «Состояние» — этап A `plan-rework.md`.
